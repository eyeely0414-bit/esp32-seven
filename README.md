# 脑梗康复陪伴器械：软件最小闭环

## 1. 产品目标

面向脑梗康复人群，构建软硬件一体的康复陪伴产品。

长期软件能力：

- 依据用户情况制定训练计划，并呈现阶段目标与预期趋势。
- 在训练过程中提供陪伴、提醒、监督和鼓励。
- 记录训练表现与情绪表现，并向授权的家属、康复治疗师或医生同步关键信息。

医疗边界：产品不能承诺康复效果，也不能在没有专业规则和人工介入机制时给出诊断、处方或高风险训练建议。

## 2. 当前阶段：无屏语音 MVP

本阶段只验证一条最小语音交互链路：

```text
用户按住按键说话
    -> ESP32 采集语音
    -> Wi-Fi 发送到电脑本地后端
    -> 百度 ASR 转文字
    -> DeepSeek 生成简短陪伴式回复
    -> 百度 TTS 转语音
    -> ESP32 扬声器播放回复
```

推荐交互方式为“按住说话、松开提交”，而不是一开始做唤醒词或全双工实时对话。

无屏状态反馈由声音承担：

- 开机两声短音：设备就绪。
- 随后两个高音短音：Wi-Fi 已连接且电脑后端可访问。
- 按住按键一声短音：开始录音。
- 松开按键两声短音：录音已提交、等待处理。
- 低沉提示音：Wi-Fi、后端或语音服务异常。
- AI 的 TTS 音频：最终回复。

## 3. 当前硬件

- ESP32-WROOM-32 开发板，带 CH340，可连接 Wi-Fi。
- INMP441 I2S 麦克风。
- MAX98357A I2S 功放。
- 4 欧 3W 扬声器。
- 独立按键。
- 原 0.96 英寸 OLED（SSD1306 标称）暂不纳入 MVP。

## 4. 无屏版本固定接线

所有模块共地；接线或拔线前断开 USB。

| 模块 | 模块引脚 | ESP32 引脚 |
|---|---|---|
| INMP441 | VDD | 3V3 |
| INMP441 | GND | GND |
| INMP441 | SCK | GPIO26 |
| INMP441 | WS | GPIO25 |
| INMP441 | SD | GPIO34 |
| INMP441 | L/R | GND |
| MAX98357A | VIN | 5V |
| MAX98357A | GND | GND |
| MAX98357A | BCLK | GPIO26 |
| MAX98357A | LRC | GPIO25 |
| MAX98357A | DIN | GPIO27 |
| MAX98357A | SD | 3V3 |
| MAX98357A | GAIN | 不接 |
| 按键 | 一端 | GPIO32 |
| 按键 | 另一端 | GND |

GPIO26 是麦克风 SCK 与功放 BCLK 的共享 I2S 时钟线；GPIO25 是麦克风 WS 与功放 LRC 的共享 I2S 帧同步线。

## 5. 已验证与待验证

### 已验证

- ESP32 可通过 USB 串口正常烧录。
- PlatformIO 工程可正常编译。
- 独立按键曾被 GPIO32 正常读取。
- MAX98357A 与扬声器曾清晰播放测试提示音。
- INMP441、按键、MAX98357A 与扬声器在无屏接线下可联合工作。
- ESP32 已连接 Wi-Fi，并已通过局域网访问电脑本地后端。
- 已实现并实测：16 kHz PCM 录音 → 百度 ASR → DeepSeek → 百度 TTS → 扬声器播放。
- 端到端测试已正确识别中文问句并播放中文回复。

### 当前限制

- 单次录音上限约 2 秒，应使用短句测试。
- 后端运行在电脑本机；电脑须开机、联网，并与 ESP32 处于同一局域网。
- 电脑切换 Wi-Fi 后，局域网 IP 可能变化，需要更新 `include/secrets.h` 的 `BACKEND_HOST` 并重新烧录。

## 6. 后端与密钥原则

后端第一版运行在本电脑，ESP32 与电脑连接相同 Wi-Fi，通过电脑局域网 IP 访问后端。

- DeepSeek API：负责文本对话。
- 百度 ASR：负责语音转文字。
- 百度 TTS：负责文字转语音。
- API Key、Secret 等只保存在电脑后端的 `.env` 文件，绝不写入 ESP32 固件，也不要发到聊天中。

## 7. 明确暂缓的内容

- OLED 不作为当前 MVP 的必要部件。此前 I2C 扫描能发现 `0x3C`，但面板无法显示；后续更换显示屏后再单独恢复。
- 不在当前阶段加入训练计划、康复效果预测、情绪识别、家属端、云部署、唤醒词或全双工实时语音。

## 8. 下一步

1. 将录音上限由 2 秒扩展到可用的 5–8 秒，并显示/播报处理状态。
2. 为“康复陪伴”定义安全的对话范围、拒答与紧急情况提示策略。
3. 增加本地训练日志：时间、时长、转写、回复、用户主观状态。
4. 在显示屏问题解决后，单独恢复屏幕状态提示；不影响语音链路。
